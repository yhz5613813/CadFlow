# Text2CAD workpiece render

This artifact reconstructs Text2CAD v1.1 sample `0000/00003775` with CadFlow's
public Python API. The sample's `part_1` is the cylindrical body and its inner
loop is the axial bore; `part_2` and `part_3` are the two radial cut features.
The original normalized coordinates are converted to millimetres with a
uniform factor of 100.

The source dataset is distributed under CC BY-NC-SA 4.0. See `report.json` for
the measured geometry, validation result, and exact source archive path.
