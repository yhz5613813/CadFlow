# Text2CAD boiler workpiece

This artifact assembles local Text2CAD components into a boiler-like vertical
pressure-vessel exterior: cylindrical shell, dished heads, foundation ring,
four legs, reinforcement bands, chimney, safety valve, offset manhole with
bolts, front furnace door and burner, feedwater/steam connections, steam riser,
pressure-gauge branch and bracket, sight-glass water-level gauge, and bottom
blowdown connection.

The geometry is intended for visual CAD and real-time preview. It is not a
pressure-vessel certification model: the shell is a solid exterior envelope,
and no fluid, heat, wall-thickness, or structural simulation is included.
Source attribution and measured validation are in `report.json`.
