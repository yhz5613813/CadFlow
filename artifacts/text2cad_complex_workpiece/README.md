# Complex Text2CAD workpiece

This artifact combines two local Text2CAD v1.1 samples into a drivetrain
workpiece. Sample `0015/00150738` supplies the flange, hexagonal hub, stepped
shaft, and keyway dimensions. Sample `0069/00694843` supplies the circular
mounting-hole component pattern.

The assembled single solid has an 18-tooth drive plate, an eight-hole bolt
circle, a hexagonal hub, two shaft stages, an axial bore, a longitudinal
keyway, and a radial pin hole. See `report.json` for measured geometry,
validation evidence, assumptions, and dataset attribution under CC BY-NC-SA
4.0.
