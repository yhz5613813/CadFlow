# Text2CAD connected fixture

This artifact expands the Text2CAD gear-shaft and bracket components into a
connected fixture: a four-hole base, twin support towers, four gussets, an
upper bridge, a front tie rod, a transverse drive shaft, collars, retaining
nuts, four clamp bolts, an 18-tooth drive hub, a keyway, and a radial pin hole.

The source dimensions come from Text2CAD v1.1 samples listed in `report.json`.
The assembly placement and enlarged base are explicit reconstruction choices;
the dataset is attributed under CC BY-NC-SA 4.0.
