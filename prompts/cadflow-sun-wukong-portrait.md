# CadFlow 孙悟空头像精细建模 Prompt

你是一个 CAD 建模 Agent，当前工作目录是 CadFlow 项目根目录。开始前必须读取：

1. AGENTS.md
2. skills/cadflow-model-part/SKILL.md
3. skills/cadflow-model-part/references/public-api.md

## 硬性接口约束

- 只能使用 CadFlow 的公开 Python 前端：import cadflow as cad、
  cad.Model、cad.Shape 以及文档中列出的公开模块。
- 禁止导入 cadflow._engine、OCP/OpenCascade、私有 shape handle、ctypes
  或直接加载 C++ 动态库。
- 不能用一张外部图片、纹理或 SVG 冒充头像。头像必须由 CadFlow 几何实体
  和布尔/变换操作生成。
- 所有尺寸使用 millimetres；脚本中声明一个统一的单位假设。
- 使用一个 with cad.Model() as model: 会话，保留每个特征的中间变量。
- 每完成一个重要特征都打印 kind、volume 或 bbox 中至少一项，失败时
  保留清晰的阶段名称和异常信息。

## 建模目标

创建一个高细节、可渲染的三维孙悟空头像，不要身体、底座或文字标签。目标
是“几何雕塑风格”的头像：猴脸轮廓、突出的眉骨和颧骨、深眼窝、眼球、
宽鼻、嘴唇、外张耳朵、头发、金色头箍和顶部翎羽都必须可以在等轴测图中
辨认出来。

采用以下坐标系：

- Z 轴向上。
- X 轴左右对称，头像中心在 X=0。
- 头像正面朝负 Y，脸部最前方约为 Y=-34。
- 头部底部约为 Z=0，顶部翎羽不超过 Z=105。
- 头像总宽约 78 mm，总深约 62 mm，总高约 105 mm。

## 必须实现的几何层级

### 1. 颅骨和面部轮廓

- 用至少四个不同高度的圆形截面和 model.loft 创建主颅骨：
  - Z=4, radius=23
  - Z=18, radius=31
  - Z=43, radius=32
  - Z=64, radius=25
- 截面中心可以沿 Y 方向轻微后移，使后脑勺比面部更圆。
- 在左右脸颊各添加一个部分嵌入颅骨的圆角体或 loft 体，形成猴脸的
  颧骨/面颊体积；左右位置必须对称。
- 最终颅骨、面颊和面部附加体应当通过重叠后 model.union 融合，不得
  直接丢弃无法融合的特征。

### 2. 耳朵

- 左右各一个外张的大耳朵，耳朵中心约为
  X=+-34, Y=-1, Z=38。
- 用沿 X 方向的多个 circle_profile(normal=(1,0,0)) 和 model.loft
  近似椭圆耳廓，外耳最大半径约 13 mm。
- 每只耳朵增加一个半径较小的内耳实体或浅凹槽，内耳颜色不是必需的，
  但轮廓必须在 PNG 中可见。

### 3. 眼睛和眉骨

- 在 X=+-12, Y=-27, Z=30 创建左右眼窝：用球体 cutter 对颅骨做
  浅切除，不能切穿后脑。
- 每个眼窝内嵌入一个半径约 5 mm 的眼球实体，再嵌入半径约 2 mm 的
  虹膜/瞳孔实体；这些实体必须与眼窝周围结构有稳定重叠或作为明确的
  多实体细节保留，不能消失。
- 在两只眼睛上方创建厚实、向外上方倾斜的眉骨。可以使用
  polyline -> face -> extrude 形成眉骨楔体，或者使用 loft/圆角实体。
- 左右眉骨、眼窝和眼球必须关于 X=0 对称，允许不超过 0.1 mm 的数值误差。

### 4. 鼻子、口鼻和嘴

- 鼻梁从面部向负 Y 突出，使用旋转后的 cone、loft 或球体组合建立；
  鼻梁宽约 10 mm，鼻尖约在 Y=-38, Z=22。
- 鼻翼左右各添加一个小圆角实体，并在鼻孔位置做两个浅切孔或暗槽。
- 口鼻部向前突出约 5 mm，形成明显的猴嘴口吻。
- 添加上唇和下唇两个薄实体；在嘴中央切出一条宽约 13 mm、深约
  1.5 mm 的弧形或窄槽，使闭嘴轮廓清楚。
- 不要只用一个圆柱表示鼻子；鼻梁、鼻尖、鼻翼和鼻孔必须是独立命名
  的建模阶段。

### 5. 毛发

- 创建头顶和后脑的毛发体积，至少使用 12 个相互重叠的锥台、loft 体或
  sweep 体形成分层毛束。
- 正面额头两侧的毛束应向外上方倾斜；后脑毛束应沿头部外轮廓排列。
- 毛束不得全部是相同方向的竖直圆锥。用循环根据角度计算每个毛束的
  平移和旋转，至少改变其倾斜方向和半径。
- 至少有一圈短毛束包围头箍上方，形成清晰的发际线。

### 6. 金色头箍

- 用 X-Z 平面上的矩形截面 polyline -> face -> revolve 创建环绕 Z 轴
  的头箍，环带高度约 6 mm，半径约 29--34 mm，位置约在 Z=58。
- 头箍必须与颅骨有可靠重叠，以便导出后不会漂浮。
- 在额头正中增加一个椭圆或菱形的头箍装饰片，装饰片向负 Y 突出。
- 不要求材质颜色，但头箍的几何边界必须能在 PNG 中识别。

### 7. 顶部翎羽

- 在头箍顶部创建至少三根逐渐变细、方向不同的翎羽。可以使用
  cone、loft、polyline -> face -> extrude 或 sweep 组合。
- 中央翎羽最高，左右翎羽略低并向外倾斜。
- 翎羽根部必须嵌入头箍或头发，避免成为无关的漂浮实体。

## 操作顺序

按下列顺序建立并验证中间结果：

1. 颅骨 loft。
2. 面颊、耳朵和后脑毛发主体。
3. 眉骨、鼻子、口鼻和嘴唇等加法特征。
4. 眼窝、鼻孔和嘴槽等减法特征。
5. 眼球、虹膜、毛束、头箍和翎羽。
6. 对称性、包围盒、拓扑和网格检查。
7. STEP/STL 导出。
8. 关闭 cad.Model 会话后，调用公开诊断渲染接口生成 PNG。

如果两个实体本应连接但布尔融合失败，检查位置、方向和重叠量；必要时
让它们嵌入 0.3--1.0 mm 后重算。不得静默删除该特征。若某个装饰细节
确实无法与主实体融合，可将其作为明确记录的多实体细节保留，并在报告中
写出最终 topology["solids"] 数量。

## 验证要求

最终脚本必须输出并保存 JSON 指标，至少包含：

- kind
- volume
- area
- center_of_mass
- bbox
- topology
- mesh 的顶点/三角形数量
- 特征阶段列表

必须检查：

- 左右眼、眉骨、耳朵和翎羽的 X 对称性。
- 包围盒在约 [-39,39] × [-35,27] × [0,105] 范围内。
- 眼窝和嘴槽确实是切除而不是只创建了外部装饰。
- PNG 不为空、尺寸至少为 2400 x 1600，并且不是纯色或空白图。
- STEP、STL、PNG 和 JSON 都存在且文件大小大于 0。

## 必须输出的文件

创建脚本：

    examples/cadflow_sun_wukong_portrait.py

将产物写入：

    examples/out/cadflow_sun_wukong_portrait/

至少生成：

    sun_wukong_portrait.step
    sun_wukong_portrait.stl
    sun_wukong_portrait.png
    sun_wukong_portrait_metrics.json

关闭建模会话后，使用公开接口渲染：

    from cadflow.inspect import brep

    brep.render_step_views_rpath(
        step_path=step_path,
        output_path=png_path,
        title="CadFlow Sun Wukong portrait",
        image_size=(18.0, 12.0),
        dpi=180,
        show_brep_edges=True,
    )

最后报告特征顺序、关键尺寸、最终几何指标、PNG 尺寸和所有输出文件的
绝对路径。不要声称没有实际查询或验证过的细节。
